# 角色工作台 · Windows 便携版

版本：0.16.0-portable.1。适用于 Windows 10 / 11 的普通 x64 电脑，使用 Edge 或 Chrome。

这是一个本地三维摆姿与构图工作台：先摆人物、动作、物品、灯光和镜头，导出参考图，再交给你自己的 AI 绘图工具完成插画。

## 三步启动

1. 右键 ZIP，选择“全部解压”。放在你有写入权限的文件夹，例如桌面；不要在压缩包内部直接运行。
2. 双击 **Start-Workbench.cmd**。程序会自动打开浏览器。黑色启动窗口需要保留。
3. 浏览器没有自动打开时，把启动窗口显示的 `http://127.0.0.1:端口/` 地址复制到 Edge 或 Chrome。

不需要安装 Node.js、Python、Blender、ComfyUI 或显卡计算环境。首次打开也不需要联网下载模型。关闭启动窗口即可停止；再次双击启动即可继续。

## 先试这几个操作

- **场景**：选择人物或物品，拖动箭头改变位置；可以添加角色、桌椅、箱子、建筑块和水族馆物件。不同角色目前是同一个示例模型的独立副本，可以分别摆姿。
- **动作**：挑选已有基础动作，再调身体关节。场景页还有“站立、蹲下、跪下、坐地”和“坐到座椅上”。
- **手部 / 表情**：调整左右手、指型、双手接触、低头、视线和闭眼等。
- **光线**：调整主光、环境补光、灯的位置、圆形或方形发光面和光斑。
- **镜头**：调整拍摄位置、焦距和构图。拖动自由观察视角后，要在镜头页把当前视角用于拍摄；导出以“最终取景”为准。
- **镜头卡片**：保存一个完整镜头，然后点“导出 AI 参考包”，得到同一机位的正常光与打灯参考，还有深度、分色和局部细节。
- **保存项目**：保留整个场景。已有项目可以从页面底部重新打开。

导出的图片在本文件夹内的 **导出** 目录；参考包在 **导出 / AI参考包**。工作记录在 **local-data**。要换文件夹或备份，请先关闭启动窗口，再复制整个工作台文件夹。

## 轻薄本的使用建议

本版实时预览最高约 30 帧，每个显示像素渲染一次，降低高分辨率屏幕的预览负担；最终图片仍按镜头设置的尺寸导出。

先用 1 个角色和少量物品试用；复杂多人场景、面积灯和高分辨率导出会更慢。需要浏览器支持 WebGL 2，画面性能取决于集成显卡和驱动，不保证每一台轻薄本都同样流畅。遇到黑屏，先尝试最新版 Edge 或 Chrome，并检查浏览器的图形加速是否正常。

## AI 怎么帮我摆

工作台本身没有聊天模型，也不自带图片生成模型。手动操作可以完全离线使用。

如果你的 AI 助手能读写本机文件、运行命令（例如本地 Codex），先启动工作台，再让它打开本文件夹，阅读 **给AI看的说明.md**。AI 可以读取当前现场并提交可撤销的场景指令。普通网页聊天不能自动控制你电脑里的这个工作台。

## 本包包括什么

- 已构建的网页、运行程序、Windows x64 Node.js v22.23.3 运行时。
- VRoid Project 的 AvatarSample_A 示例角色、独立关节配置和本地制作的手势。
- 7 个许可允许随包分发的动作预设、站蹲跪坐功能、3 个内置多人组合。
- 一个全新的单人桌椅示例；没有附带提供者的私人作品、个人镜头卡片、导出图或连接记录。
- 程序源码与第三方许可，便于本地 AI 助手理解接口。

部分本机动作库素材禁止再分发，未放入本包；详见 **第三方素材说明.md**。导出修手资料可用，但本包没有 ComfyUI 或它的模型。

## 常见情况

- **“拒绝连接”**：确认黑色启动窗口仍开着，使用它显示的地址。不要套用别人电脑的地址或端口。
- **启动窗口显示错误**：保留完整报错，发给提供者；不要只转发网址。
- **端口被占用**：程序会尝试附近的空闲端口，以启动窗口显示的地址为准。
- **浏览器说编辑会话失效**：在页面右上角点“重新连接”，尽量只保留一个工作台编辑标签页。
- **导出时比较慢**：等待当前导出完成，减少人物或物品数量，再尝试较小的输出尺寸。

原程序在本机浏览器完成验证；便携版的 Windows 路径规则已检查。最终流畅度和双击启动体验仍需在接收者的 Windows 电脑上确认。
